Contact by email and feedback packages

If you write to us or send a feedback package from LayerFrame, we process the information only to handle your request (Art. 6(1)(b) or (f) GDPR). A feedback package only contains what you selected in the program; project data is never attached. We delete the data as soon as it is no longer needed, at the latest after period, e.g. 12 months.

The LayerFrame program

LayerFrame does not send usage data. Internet connections only occur through features you use yourself – such as basemaps, web services, open data or a cloud AI provider. The privacy policies of those providers apply.
